# Logo NutraSyn Lab — variaciones de marca

Todo generado a partir del logo oficial (el mismo que usa el sitio en `index.html`/`portafolio.html`). Los `.svg` son los archivos maestros (vectoriales, se pueden escalar a cualquier tamaño sin perder calidad); los `.png` son exportaciones listas para subir directo a cada plataforma.

## ¿Cuál uso para qué?

| Necesito... | Usa este archivo |
|---|---|
| Foto de perfil de WhatsApp Business | `whatsapp-icon-navy-1024.png` |
| Foto de perfil de WhatsApp (alternativa color) | `whatsapp-icon-emerald-1024.png` |
| Ícono para poner sobre tu propio fondo/diseño | `whatsapp-icon-transparent-1024.png` |
| Foto de perfil Instagram / Facebook / LinkedIn (fondo oscuro) | `social-profile-navy-1080.png` |
| Foto de perfil Instagram / Facebook / LinkedIn (fondo claro) | `social-profile-white-1080.png` |
| Logo para un documento o presentación con fondo blanco | `logo-full-black-2000w.png` |
| Logo para un documento o presentación con fondo oscuro | `logo-full-white-2000w.png` |
| Portada / banner / firma de correo | `logo-banner-navy-1600x400.png` |
| Favicon del sitio web (ya está integrado, referencia) | `favicon-512.png`, `favicon-192.png`, `favicon-32.png`, `favicon-16.png` |
| Ícono de app / recorte especial | `favicon-transparent-512.png` |
| Editar o escalar el logo en Illustrator/Figma/Canva | los archivos `.svg` |

## Archivos maestros (SVG)

- `logo-icon-*.svg` — solo el símbolo de la llama, sin texto (negro / blanco / esmeralda / navy).
- `logo-full-*.svg` — el logotipo completo "NUTRASYN LAB" (negro / blanco / esmeralda / navy).

Todos con fondo transparente, listos para colocar sobre cualquier color.

## Notas

- El ícono es alto y angosto, así que en los formatos cuadrados (WhatsApp, redes sociales) se dejó bastante margen alrededor a propósito — así no se corta cuando la plataforma lo recorta en círculo.
- Estos archivos se generaron a partir del logo vectorial original (mismo trazo, mismos colores de marca: navy `#0A2540` y esmeralda `#00A896`), no son una reinterpretación del diseño.
